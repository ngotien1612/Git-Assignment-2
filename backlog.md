# Product Backlog - Git Workflow Assignment

This backlog contains the user stories for our software development team project, simulating Agile practices.

## User Stories

### US-101: Authentication
- **ID:** US-101
- **User Story:** *As a user, I want to log in to the system using my credentials, so that I can securely access my personal account and protected features.*
- **Priority:** High

### US-102: Dashboard Overview
- **ID:** US-102
- **User Story:** *As a registered user, I want to view a dashboard with an overview of my recent activities, so that I can quickly track and manage my primary information.*
- **Priority:** Medium

### US-103: User Profile Management
- **ID:** US-103
- **User Story:** *As a user, I want to update my profile information and change my avatar, so that my personal details remain accurate and up to date.*
- **Priority:** Medium

### US-104: Application Settings
- **ID:** US-104
- **User Story:** *As a user, I want to change my account settings and notification preferences, so that I can customize my application experience to my liking.*
- **Priority:** Low
